# Enta Website

The Enta marketing website, built with Next.js and served from `/enta-website`.

## Development

```bash
npm ci
npm run dev
```

Open `http://localhost:3000/enta-website`.

## Verification

```bash
npm run check
```

The check command runs TypeScript, ESLint, and a production build.
